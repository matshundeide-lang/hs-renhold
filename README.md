# HS Renhold

Static multipage website for HS Renhold. Built with plain HTML, CSS and JavaScript.

## Netlify

- Build command: leave blank
- Publish directory: `.`
- Contact form: Netlify Forms, form name `foresporsel`

The service pages live under `tjenester/`; each directory contains an `index.html` so the URL stays clean. The site includes pages for businesses, private homes, moving cleans, stairwells, window cleaning and exterior washing, plus sameier/borettslag, about, contact and privacy.

## Before final public launch

- Confirm which legal entity is the data controller for the contact form.
- Configure Netlify Forms processing and email notifications to the chosen HS Renhold inbox.
- Add the final custom domain, then publish a sitemap with that domain.
- Review the service descriptions and service area against actual capacity.
